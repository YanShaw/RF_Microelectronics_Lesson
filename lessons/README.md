## 状态定义

- 已生成：完整正文已经写入文件并通过本课自查。
- 已讲授：已在对话中提供完整内容；这不等于用户已经掌握。
- 已掌握：用户的推导、计算或解释提供了支持证据；记录具体证据与待改进点。
- 未评估：尚无足够学习证据。补讲和练习不改正式课号。
